How I work

One loop: discover, decide, deliver, learn.

Every project runs through the same four moves. Frameworks are tools I reach for when they fit, not a checklist.

01 Discover

Find the real problem behind the request.

A CRM evaluation that was really a billing problem

Reach for: Jobs to be done, signal taxonomies
02 Decide

Make the trade-off explicit, then make the call.

Clinical-output changes treated as one-way doors

Reach for: Build vs buy, one-way vs two-way doors
03 Deliver

Specify the flow, including where it breaks.

A radiologist reporting module, taken from PRD through release

Reach for: User stories and acceptance criteria, failure modes
04 Learn

Measure before you automate.

Defect tracking that cut product failures 40%

Reach for: Build–measure–learn, reason codes
